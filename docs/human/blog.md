# Блог

Блог есть и на сайте, и в админке. Это одни и те же записи.

На сайте список постов открывается из меню «Блог». Отдельный пост открывается по адресу `/blog/post/{slug}`. Показывается запись, если она активна. В локальной базе 32 поста, все активны.

У поста есть заголовок, короткая адресная часть, краткое описание, текст, картинка и поля для поиска. Старые записи могут хранить главную картинку прямо в поле поста. Новые картинки крепятся к посту отдельно.

В админке раздел «Блог» показывает список и даёт создать или править пост. Создавать и менять пост могут администратор и менеджер. Обзорный пользователь видит раздел, но сохранение ему закрыто. Удалить пост может только администратор.

Текст шапки страницы блога на сайте — это не сам пост. Он лежит в контенте фиксированной страницы с ключом `blog`.
