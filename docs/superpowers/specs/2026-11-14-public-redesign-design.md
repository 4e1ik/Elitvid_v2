# Редизайн публичного сайта Elitvid

## Цель

Перенести готовые экраны страницы «ребрендинг» из копии макета на текущий сайт. Сборка — компоненты Blade и CSS. Админка остаётся в старом виде.

Макет: https://www.figma.com/design/JO6HaDjZj7B9RgwmNe31ln/ELITVID--Copy-?node-id=8-21536

Страницы файла «старое» и «не согл» в этот заход не входят.

## Что меняется

| Место | Что происходит |
|---|---|
| Главная | Новая вёрстка по кадру «главная», включая мобильный кадр |
| Направления | Новая вёрстка по кадру «каталог» («Наши направления»), включая мобильный кадр. Пункт меню «Каталог» ведёт сюда |
| Блог | Новая вёрстка списка по кадру «блог» («Наши новости»), включая мобильный кадр |
| Остальные публичные страницы | Новые шапка и подвал. Тело страницы остаётся старым |
| Админка | Без изменений |

Кадры «контакты» и «Форма для обратной связи» — это состояния, а не новые адреса. «Контакты» открывает список почты и телефонов из макета. «Оставить заявку» открывает текущую форму в новом виде.

## Компоненты

Отдельные компоненты макета, у каждого есть десктоп и мобильная версия:

- кнопка;
- шапка;
- подвал.

Повторяющиеся блоки:

- карточка направления;
- карточка статьи;
- поле ввода;
- форма заявки.

Шапка содержит меню «Главная», «Каталог», «Блог», «Контакты», кнопку «Корзина» и кнопку «Оставить заявку».

Блоки главной, которые встречаются один раз, остаются частями страницы: цифры, партнёры, видео, примеры работ.

Скрипт только для открытия мобильного меню, списка контактов и формы. Остальное — CSS.

## Данные

Тексты главной и страницы направлений берутся из макета. Если текст сейчас правится в админке, он обновляется там. Если он записан в шаблоне, меняется файл шаблона.

Записи статей блога не меняются. Меняется только вид карточки и страницы списка. На странице остаются все статьи из админки.

Картинки скачиваются из макета и сохраняются в WebP. Слот, который заполняется через админку, обновляется в админке. Файл, который лежит в сайте, кладётся в файлы сайта.

## Форма и корзина

Форма отправляется как сейчас: те же поля, те же страны и коды, те же сообщения об ошибках. Меняется вид.

«Корзина» видна и по нажатию ничего не делает: нет запроса и нет перехода.

## Проверка

- Главная, направления и блог на ширине макета и на мобильной ширине совпадают с кадрами.
- На странице товара новая шапка и подвал, тело старое.
- Заявка по-прежнему уходит.
- «Корзина» ничего не делает.
- После изменений обновляются `docs/ai` и `docs/human`.

## Вне этого захода

Страницы товара, коллекций и отдельных направлений не переверстываются. Корзина не хранит товары. Админка не меняет внешний вид. Новые адреса не создаются.
