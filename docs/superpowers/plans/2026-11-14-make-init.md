# make init Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make init` поднимает контейнеры, создаёт `elitvid_db`, импортирует дамп и готовит Laravel одной командой, спрашивая только когда не хватает файлов или база уже заполнена.

**Architecture:** `Makefile` вызывает `scripts/init.sh`. Чистые решения (файлы, действие с базой, ключ, ordered SQL) тестируются без Docker. Скрипт сам запускает compose, ждёт MariaDB и выполняет импорт и artisan.

**Tech Stack:** bash, GNU Make, Docker Compose, MariaDB 10.3, Laravel artisan, composer.

## Global Constraints

- Ничего не скачивать.
- Дамп: `cr48940_elitvid.sql` в корне.
- Картинки: файл в `storage/app/public/` кроме `.gitignore` и файл в `public/elitvid_assets/newDesign/newDesign/files/`.
- `imgs/` не проверять.
- Ответы только `1` и `2`, читать из `/dev/tty`.
- Нет терминала и не хватает файлов: выход 1, базу не менять.
- Нет терминала и таблицы уже есть: оставить данные.
- Пустая база: не запускать `migrate`.
- `APP_KEY` не перезаписывать. Нет `.env`: ошибка, файл не создавать.
- Уже существующий `public/storage` — успех.
- Импорт той же командой, что `make db-import`.
- `MYSQL_DATABASE=elitvid_db`, том `mysql_data`, healthcheck `mysqladmin ping` каждые 5 секунд, timeout 5 секунд, 12 попыток.
- Ждать MariaDB не дольше 60 секунд, проверка раз в 2 секунды.
- Базу `wd05` не удалять.
- `.env` и `.env.example` не менять.
- `make app` и `make db-import` не менять по поведению.
