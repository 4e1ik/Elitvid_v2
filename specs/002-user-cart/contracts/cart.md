# Contract: Корзина

| | |
|---|---|
| Страница | `GET /cart` |
| Добавить | `POST /cart/items`, поле `product_id` |
| Количество | `POST /cart/items/{product}`, поле `quantity` |
| Очистить | `POST /cart/clear` |
| Кто | посетитель без входа |

Добавление принимает только активную скамейку или кашпо. Повтор того же `product_id` увеличивает количество на 1.

Количество `0` убирает строку. Количество меньше 0 не принимается.

Кнопка «Корзина» в шапке открывает `GET /cart`. На странице товара одна кнопка «В корзину» на товар, не на размер.
