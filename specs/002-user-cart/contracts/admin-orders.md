# Contract: Заказы в админке

| | |
|---|---|
| Список | `GET /admin/orders` |
| Выгрузка | `GET /admin/orders/export` |
| Доступ | роли `admin` и `manager`, как у `/admin/mails` |
| Страница | 20 заказов, новые сверху |
| Фильтр | `date_from`, `date_to`, формат даты дня. Пустое значение границу не ставит. День «с» и день «по» включены |
| Выгрузка | те же `date_from` и `date_to`, все заказы выборки, не только текущая страница |
| Столбцы | Дата, Имя, Почта, Телефон, Организация, Комментарий, Товары |
| Строка | один заказ. Товары в последнем столбце: `Название × количество`, несколько товаров через `; ` |
| Пустая выборка | список пуст, файл содержит только строку столбцов |
