# Contract: Заявка из корзины

| | |
|---|---|
| Метод и адрес | `POST /cart/order` |
| Обязательные поля | `name`, `email`, `phone`, `g-recaptcha-response` |
| Необязательные поля | `country`, `name_corp`, `textarea` |
| Файла нет | поле `file` не принимается |
| Телефон | то же выражение, что в `MailRequest`: `29`, `33`, `44`, `25` и семь цифр, либо `9` или `7` и девять цифр |
| Длины | имя и почта до 50, организация до 50, комментарий до 100 |
| Проверка человека | тот же запрос к Google, что у окна заявки. Отказ: «Похоже, что вы - Робот!» |
| Пустая корзина | заказ не создаётся |
| Недоступный товар | заказ не создаётся, корзина не очищается |
| Успех | заказ и строки в базе, корзина пустая, сообщение на странице корзины, запись в `storage/logs/laravel.log`. Письмо не отправляется |
