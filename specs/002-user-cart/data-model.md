# Data Model: Корзина и заявки

## Корзина

Не таблица. Ключ сессии `cart`: словарь `id товара → количество`.

- Количество — целое число от 1. Ноль удаляет строку.
- В корзину попадает товар с `active = 1`, `product_type` `bench` или `pot`, без мягкого удаления.
- Тот же товар второй раз увеличивает количество, новую строку не создаёт.
- Очистка и успешная заявка записывают пустой словарь.

## Order

Таблица `orders`.

| Поле | Правило |
|---|---|
| name | обязательное, строка, в форме не длиннее 50 |
| email | обязательное, почта, в форме не длиннее 50 |
| phone | обязательное, страна и цифры, как у письма |
| corporation_name | необязательное, в форме не длиннее 50 |
| comment | необязательное, в форме не длиннее 100 |
| created_at | день для фильтра «с» и «по», границы включительно |

Заказ не удаляется фильтром и выгрузкой.

## OrderItem

Таблица `order_items`. Принадлежит одному заказу.

| Поле | Правило |
|---|---|
| order_id | обязательная связь с заказом |
| product_id | товар на момент заявки, может стать пустым, если товар позже удалят физически |
| product_name | название на момент заявки, до 255 символов |
| quantity | целое от 1 |

Размера, веса, цены и цвета в строке нет.

## Переходы

1. Пустая корзина — заявку отправить нельзя.
2. В корзине есть недоступный товар — заявка не создаётся, корзина остаётся.
3. Данные или проверка «я не робот» неверны — заказ не создаётся, корзина остаётся.
4. Данные верны — создаются заказ и строки, корзина пустеет, в журнал пишется текст заказа.
