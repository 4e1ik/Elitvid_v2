# Contract: поля форм админки

Маршруты существующие, новых нет (сверено с `routes/web.php`).

## `PUT images.update` (правка картинки)

| Поле | Правило | Смысл |
|---|---|---|
| `main_image` | `sometimes`, `boolean` | `1` — сделать главной; `0` — снять отметку. Шлёт только форма картинки товара (скрытое `0` + чекбокс `1`). |

## `POST products.store`, `PUT products.update` (загрузка новых картинок)

| Поле | Смысл |
|---|---|
| `image_data[i][main_image]` | `1` у загружаемой картинки, отмеченной главной. Чекбоксы в превью взаимоисключающие. |

## Страница товара

`<img id="first_image" data-color="…" data-texture="…">` — начальное состояние переключателей в `imageUpdater.js`.
