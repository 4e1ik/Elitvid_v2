# Data Model: Главная картинка товара

Схема не меняется.

## Image (`images`)

| Поле | Значение для товара |
|---|---|
| `imageable_type` | `App\Models\Product` |
| `imageable_id` | id товара |
| `color`, `texture` | цвет и текстура (у кашпо и урн) |
| `main_image` | `1` — отмечена главной; у товара не больше одной |

## Product

- `mainImage(): ?Image` — картинка с `main_image = 1`, иначе с наименьшим `id`, иначе `null`.

## Правила

- Сохранение картинки товара с `main_image = 1` → у остальных картинок товара `main_image = 0`.
- Удаление главной → главной становится картинка с наименьшим `id` (без записи в базу).
