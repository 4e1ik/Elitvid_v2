# Quickstart: проверка правок 004

**Предусловия**: сайт поднят (`make init` уже сделан), http://localhost:8080 отвечает. Эталон — PNG-кадры «ребрендинг» (1440 — `~/Downloads/ELITVID (Copy) (1)`, 320 — `~/Downloads/ELITVID (Copy) (2)`).

## 1440 px

1. `/` — сверить с кадром «главная» сверху вниз: первый экран (3 строки заголовка), «звезда» и слоган, фото «Парклеты, навесы», подписи кнопок не жирные, маркеры в «Почему выбирают», орнамент без чёрного фона, заголовок «Нанесение…» в 2 строки, «БОЛЬШЕ ПРИМЕРОВ», подвал.
2. `/napravleniya` — фон первого экрана, заголовок «НАШИ / НАПРАВЛЕНИЯ», «звезда».
3. `/blog` — фон первого экрана, «НАШИ / НОВОСТИ», кнопки «Читать далее» в ряду на одной линии.
4. Нажать «Контакты» — тёмная панель с рамкой, телефоны по FR-004.
5. Нажать «Оставить заявку» — зелёная рамка и кнопка «Заказать». Отправить заявку с верными данными — она появляется в админке «Заявки». Неверный телефон отклоняется.

## 320 px

6. `/`, `/napravleniya`, `/blog` — сверить с кадрами 320. `document.documentElement.scrollWidth` равен 320.
7. Открыть бургер — меню как до правок.
