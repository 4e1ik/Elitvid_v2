# Quickstart: Урны

Сайт: http://localhost:8080 (`make init` уже выполнен), миграции применены (`make app` → `php artisan migrate`).

1. «Урны» на 1440 px: `/napravleniya/urny` — крошки «Каталог › Урны», заголовок «Урны из полистоуна», текст кадра, «Оставить заявку» без «Скачать каталог», фон с урнами SKANDI, сетка по 3: SKANDI, TITAN, VEKTOR, ORION, MONRO. Сверить с PNG кадра 246-1882.
2. То же на 320 px: нет горизонтальной прокрутки.
3. «Оставить заявку» открывает форму заявки.
4. Клик по TITAN → `/napravleniya/urny/{slug}`: фото, фактуры, 8 цветов, «Материал: полимербетон», размер 500\*500\*500, «Цена: от», кнопки корзины, «Другие формы».
5. Нажать цвет и фактуру — фото не пропадает.
6. «Добавить в корзину» → «Удалить»; `/cart` показывает TITAN; «Удалить» убирает.
7. `/napravleniya/urny/cube` (slug кашпо) → 404.
8. Главная: плитка «Урны» → «Урны». Подвал (1440 и 320): «Урны» → «Урны».
9. Админка: меню «Урны» → список 5 урн; создать тестовую урну, изменить, выключить (пропала с сайта), удалить.
10. «Контент страниц»: есть «Урны».
11. `/sitemap.xml` содержит `/napravleniya/urny` и адреса 5 урн.
12. Кашпо и скамейки: `/napravleniya/kashpo/kruglye`, карточка кашпо, админка кашпо — без изменений.
13. `./vendor/bin/phpunit` (с разрешения пользователя).
