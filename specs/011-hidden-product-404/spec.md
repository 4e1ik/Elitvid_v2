# Feature Specification: Скрытый товар не открывается по прямой ссылке

**Feature Branch**: `011-hidden-product-404`

**Created**: 2026-11-25

**Status**: Draft

**Input**: User description: "Исправь поведение открытия скрытого товара по прямой ссылке. Посетитель видит страницу 404. Вошедшему в админку пользователю — то же самое, предпросмотра нет."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Скрытый товар отдаёт 404 (Priority: P1)

Администратор снимает у скамейки, кашпо или урны признак «показывать на сайте». После этого страница товара по прямой ссылке отвечает «Страница не найдена» (404) любому посетителю, в том числе вошедшему в админку.

**Why this priority**: Сейчас скрытый товар остаётся доступен по старой ссылке и в поисковиках, хотя из списков он уже убран.

**Independent Test**: Скрыть товар каждого типа, открыть его адрес и получить 404. Вернуть признак и получить страницу товара.

**Acceptance Scenarios**:

1. **Given** скрытая скамейка, **When** открыт её адрес `/napravleniya/skami/{collection}/{slug}`, **Then** ответ 404.
2. **Given** скрытое кашпо, **When** открыт его адрес `/napravleniya/kashpo/{collection}/{slug}`, **Then** ответ 404.
3. **Given** скрытая урна, **When** открыт её адрес `/napravleniya/urny/{slug}`, **Then** ответ 404.
4. **Given** пользователь вошёл в админку, **When** он открывает адрес скрытого товара, **Then** ответ тоже 404.
5. **Given** активный товар, **When** открыт его адрес, **Then** страница товара открывается как раньше.

### Edge Cases

- Старый адрес товара коллекции Street furniture перенаправляет так же, как сейчас. Если итоговая страница — скрытый товар, посетитель получает 404.
- Скрытый товар, уже лежащий в корзине, корзина по-прежнему показывает как «Товар недоступен».
- Карта сайта и списки товаров не меняются.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Страница скамейки, кашпо и урны MUST отвечать 404, если товар не отмечен «показывать на сайте».
- **FR-002**: Правило FR-001 MUST действовать одинаково для всех посетителей, включая вошедших в админку.
- **FR-003**: Страница активного товара MUST открываться без изменений.
- **FR-004**: Админка, списки товаров на сайте, корзина и перенаправления Street furniture MUST работать как раньше.

### Key Entities

- **Товар**: скамейка, кашпо или урна с признаком «показывать на сайте». Новых данных нет.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 100% скрытых товаров всех трёх типов отвечают 404 по прямой ссылке.
- **SC-002**: 100% активных товаров открываются по прямой ссылке так же, как до доработки.

## Assumptions

- Ответ 404 — обычная страница «не найдено» сайта, как для несуществующего адреса.
- Предпросмотр скрытого товара для админки не нужен (решение пользователя 2026-11-25).
