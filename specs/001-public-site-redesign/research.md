# Research: Публичный редизайн

## Decision: компоненты Blade в текущем сайте

**Rationale**: Уже выбранный способ сборки. Публичные страницы расширяют один каркас `layouts.elitvid.elitvid`, поэтому шапка и подвал меняются в одном месте и попадают на все публичные страницы, включая товар, благодарность и 404.

**Alternatives considered**: отдельные HTML-страницы и новый сборщик. Оба отвергнуты до плана: первое дублирует шапку, второе не нужно для трёх экранов.

## Decision: новый CSS рядом со старым

**Rationale**: Тела страниц без макета завязаны на `public/elitvid_assets/newDesign/newDesign/style.css`. Замена этого файла сломает их. Новый вид живёт в `public/elitvid_assets/redesign/` и не переопределяет классы старого тела.

**Alternatives considered**: переписать общий `style.css`. Отвергнуто, потому что страницы товара должны сохранить прежнее тело.

## Decision: не добавлять библиотеки и не снимать старые скрипты с каркаса

**Rationale**: Каркас сейчас подключает jQuery, Swiper и несколько файлов, которые нужны старым страницам. Этот заход их не удаляет и не добавляет новых библиотек. Новый скрипт обрабатывает только меню, контакты и форму. Три новые страницы не получают новый слайдер: движение, если оно есть в кадре, делается CSS.

**Alternatives considered**: убрать jQuery с трёх новых страниц отдельным каркасом. Отвергнуто в этом заходе: два каркаса разойдутся, а выигрыш ограничен шапкой, которая всё равно общая.

## Decision: картинки WebP в текущий слот

**Rationale**: Спецификация требует показать картинку макета тем способом, которым она показывается сейчас. Слот из админки (`static_images` и связанные файлы) обновляется через админку. Картинка, которой нет в админке, кладётся файлом в `public/` и подключается из шаблона. Перед записью файл переводится в WebP.

**Alternatives considered**: оставить временные адреса Figma. Они протухают и не подходят для сайта.

## Decision: тексты главной и направлений править в текущем хранилище

**Rationale**: Заголовок и описание для поиска уже лежат в `page_contents` по ключам `main` и `directions`. Тексты, которые собраны в шаблоне, меняются в шаблоне. Отдельного хранилища для текстов макета не создаётся.

**Alternatives considered**: завести новые поля. Отвергнуто: редактор должен менять текст тем же способом, что и раньше.

## Decision: статьи блога не записывать

**Rationale**: Список читает существующие записи `blogs`. Меняется только шаблон карточки в `resources/views/elitvid/site/blog/blog.blade.php`.

**Alternatives considered**: обновить названия статей текстами кадра. Это прямо отвергнуто.

## Decision: форма остаётся `POST /send_mail`

**Rationale**: Живая форма — `resources/views/includes/elitvid/popup_application.blade.php`, проверка — `MailRequest`, запись и письмо — `MailController`. Меняется разметка и вид. Поля, страны, коды, размер файла и проверка «я не робот» не меняются. Кнопка «Корзина» — `button` без действия и без адреса.

**Alternatives considered**: новая страница заявки и новая корзина. Обе вне спецификации.

## Decision: шрифт уже на сайте

**Rationale**: Montserrat Regular, Medium и SemiBold уже лежат как woff2 рядом со старым CSS. Новый CSS использует эти файлы и не запрашивает шрифт снаружи.

**Alternatives considered**: подключить шрифт с внешнего сервера. Это лишний запрос при уже имеющихся файлах.
