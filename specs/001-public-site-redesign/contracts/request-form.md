# Contract: Заявка

Видимая форма меняется. Запрос остаётся прежним.

| | |
|---|---|
| Метод и адрес | существующий `POST` приёма заявки |
| Обязательные поля | имя, почта, телефон |
| Необязательные поля | организация, сообщение, один файл |
| Телефон | те же страны и коды, что принимает форма сейчас |
| Файл | не больше прежнего предела |
| Проверка человека | остаётся обязательной, как сейчас |
| Отказ | прежние сообщения, заявка не сохраняется |
| Успех | прежний ответ об отправке, заявка сохраняется и письмо уходит как сейчас |

Новых полей и нового адреса у формы нет.
