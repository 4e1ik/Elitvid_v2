# Contract: Публичные страницы

Адреса не добавляются и не переименовываются.

| Действие посетителя | Адрес | Вид |
|---|---|---|
| Главная | существующий адрес главной | кадр «главная», широкий и узкий |
| Каталог в шапке | существующий адрес направлений | кадр «каталог» |
| Блог в шапке | существующий адрес списка блога | кадр «блог», карточки из текущих статей |
| Контакты в шапке | адрес не меняется | открытый список почты и телефонов из кадра |
| Корзина | адрес не меняется | кнопка видна, действия нет |
| Оставить заявку | адрес не меняется | открывается форма из [request-form.md](request-form.md) |
| Любая другая публичная страница | её текущий адрес | новая шапка и подвал, прежнее тело |

Узкий вид шапки и подвала используется на всех публичных страницах. Узкий вид всего тела есть только у главной, направлений и блога.

Страницы админки в этот контракт не входят и сохраняют свой каркас.
