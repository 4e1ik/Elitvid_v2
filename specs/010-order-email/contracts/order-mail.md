# Contract: письмо о заказе

- Получатель: адрес заявок (тот же, что у `send_mail`).
- Тема: «Заказ из корзины #<id>».
- Тело: имя, почта, телефон (с кодом страны), организация, комментарий, список названий товаров. Пустые необязательные поля — «—».
- `POST /cart/order` (`cart.place`): ответ для посетителя не меняется — redirect на `cart.show` с «Заявка принята.» и при успехе, и при сбое почты.
- `GET /admin/orders` (`admin_orders.index`): строка заказа с `mail_failed = true` содержит текст «Письмо не отправлено».
